当前这轮原创 demo（纸上展览 / 材质小剧场）方向不对。

问题不是“差一点细节”，而是你没有真正学到 reference 的核心。

你学到的是：
- 米纸背景
- 淡色调
- 纤细线条
- 文艺标题
- 一点轻动画

但你没有学到：
- 手绘对象本身的完成度
- 轮廓与填色的精细度
- 原站对象“被认真画出来”的感觉
- 原地轻微笔绘闪烁 / boil 的生命感
- 真正的手写笔迹，而不是字体替代
- 交互场景的叙事性
- 声音与动作的一致性

请你把这轮原创 demo 判定为方向性失败，不要继续在当前结果上小修小补。

==================================================
一、重新定义目标
==================================================

下一阶段不要再做“手绘主题网页页面”。

要做的是：

可游玩的 hand-drawn interactive scenes。

重点不是：
- 几个 section
- 几张 card
- 几句 slogan
- 一个 layout

重点是：
- 一个有生命感的小世界
- 一组被认真绘制的对象
- 一个能探索、能停留、能观察的交互场景
- 一种完整的视觉叙事

请停止用抽象 slogan 填空。
如果一句文字没有明确的场景功能，就不要写。

==================================================
二、先承认并总结当前失败点
==================================================

请先在文档中明确写出当前原创 demo 的主要问题：

1. Original objects are under-drawn.
   它们像示意插画或图标，不像 reference 中那种被认真设计和认真画出的对象。

2. Typography is fake-hand-drawn.
   你大量依赖字体气质，而不是笔迹式的真实手写表现。

3. The demos are page layouts, not interactive scenes.
   “Gallery” 不该只是三张纸排成一行；“motion studies” 也不该只是六个图标摆在网格中。

4. Micro-life is missing.
   缺少原站那种线条活着、轮廓轻微闪烁、对象在静止时仍有生命感的层次。

5. Audio and copy are generic.
   文案像模板化文艺句子，音效没有媒介感与动作感。

把这些问题写清楚，再开始重做。

==================================================
三、新的设计原则
==================================================

1. 手绘 = 精细绘制 + 媒介感
不是“粗糙”。
不是“线细一点、歪一点就算 hand-drawn”。

2. 每一个主要对象都必须有足够的绘制密度
包括：
- 轮廓
- 内部结构
- 填色方向
- 局部装饰
- 角色感 / 物性

不要再出现只像图标的对象。

3. Typography 必须进入这个世界
尽可能通过程序化笔迹、路径 reveal、逐笔写出、轻微不均匀字距等方式实现。
不要只靠选择一种“像手写”的字体。

4. 场景优先于页面
先思考场景中的角色、对象、空间关系、探索路径，再思考页面结构。

5. 交互必须有叙事
hover / click / selection / transition 不是单纯反馈，而是场景中的事件。

6. 静止状态也必须好看
页面即使不操作，也应像一张活着的插画。

==================================================
四、重做 demo，不沿用当前“纸上展览”和“六图标网格”的结构
==================================================

请基于现有 primitives，重新设计至少两个 demo。
这两个 demo 必须是真正的 scene-driven demo，而不是页面式 section demo。

------------------------------------------
Demo A：Paper Gallery Scene
------------------------------------------

目标：
把“gallery”做成一个可观察、可进入、可选择的小场景。

最低要求：
- 存在一个主角 / guide character（可以是一个小卡通角色）
- 主角能够在 gallery 场景里移动、停下、看向作品或与作品交互
- gallery 不是三张 card 摆一行，而是一个小型纸上展览空间
- 用户可以通过点击 / hover / 引导操作，让主角靠近某件作品
- 某件作品被选择后，进入更具体的观察状态
- 退出后回到 gallery 场景
- 场景中应包含一些 ambient doodles 或环境元素，但不能杂乱

重点：
你要证明你理解了 “gallery” 是空间、是游走、是观看过程，而不是卡片列表。

------------------------------------------
Demo B：Living Material Scene
------------------------------------------

目标：
把“材质与动作差异”做成一个小剧场，而不是六个对象排版展示。

最低要求：
- paper / leaf / bell / stone / lamp / little creature 可以保留其主题
- 但它们不应只是等间距排列的 icons
- 你需要给它们构造一个有场景感的展示方式
- 用户可以逐个触发或连续触发对象
- 每个对象必须体现明确不同的物性和动作性格
- 至少部分对象之间存在轻微关系或回应，不要完全孤立

重点：
你要证明你理解了 “same touch, different response” 应该是一段可体验的 motion theatre，而不是一个教学海报。

==================================================
五、加强对象绘制质量
==================================================

所有原创对象请提高绘制密度。

具体要求：
- 任何主要对象都不能只停留在“一个轮廓 + 少量排线”
- 参考原站对象的绘制精细度与可爱程度
- 角色类对象要有清晰的设计语言
- 普通物件也要有被认真画过的感觉
- 允许彩铅 / 蜡笔式填色不完整
- 允许线条轻微歪斜
- 但不允许因为 hand-drawn 就偷懒，导致对象像占位图标

如果需要，请为每个原创对象单独做设计迭代，而不是批量套模板。

==================================================

- 允许字距、轻重、倾斜存在自然差异
- 避免看起来像“用了一个文艺字体”

如果暂时无法全面替换，也请优先替换最关键、最显眼的文字。
