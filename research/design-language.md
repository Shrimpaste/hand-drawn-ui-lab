# 将这套手绘 UI 用于其他功能

目标是学习“纸、笔、角色与反馈如何共同表达功能”。原始插画 / 提取代码的来源说明见 README；新项目可以使用自己绘制的资产接入这些适配模块。

## 功能如何变成插画

| 功能 | 在纸上的表达 | 交互响应 |
| --- | --- | --- |
| 主要操作 | 举牌的小角色、笔、印章、信封等可辨认的道具 | 看向指针 → 预备 → 操作 → 短暂收尾 |
| 撤销 / 返回 | 弯箭头或回卷的线 | 箭头张开、说明写出、执行后留下短暂轨迹 |
| 开关 | 同一插画的不同姿态，如发声 / 闭嘴、醒 / 睡 | 状态持续可见；文字用于解释而非承担唯一的状态提示 |
| 强度 / 级别 | 逐颗填色的星星、叶子、刻度 | 填色和音高跟随级别，悬停写出当前含义 |
| 加载 / 等待 | 笔在涂圈、角色思考、轻微呼吸 | 稳定循环，完成时过渡到实际内容 |
| 空状态 | 尚未画满的纸或等人回应的小角色 | 第一条内容沿笔顺进入，周边装饰保持安静 |

插画要能说明操作。可爱装饰不能替代可理解的语义；DOM 的 label、disabled、aria-pressed 与键盘操作和画面保持同步。

## 四层美术语言

1. **纸**：暖灰底色、低对比颗粒、少量折痕。鼠标带来约 0.07 / 0.045 世界单位的跟随，tau=0.35s；本地另加约 0.1° 的最大轻微旋转。页面所有元素共用同一张纸的变换。
2. **笔**：深棕 / 蓝紫 / 红棕三支笔即可建立层次。轮廓有轻微位置差，颜色有压力浓淡，排线沿相近方向但间距不机械。
3. **形**：每个小角色由身体、眼睛、嘴、帽子 / 耳朵等独立部件组成。附件连接到身体 anchors；身体压缩时，附件和表情跟着锚点变化。
4. **动**：身体表演约 12Hz、轮廓 boil 约 8Hz；位移、目光与弹簧连续更新。不要给每一项属性都套同一个频率。

## 时序决定反馈的分量

按钮提示采用约 0.3s 写入、0.18s 擦除。写到一半离开就从当前墨迹量擦，返回则从剩余墨迹继续写，避免整词突然闪现。鼠标点击后的 focus 不应让悬停提示一直留着；键盘 focus-visible 则需要持续显示。

移动反馈包括预备、离地 / 脚步、位移、落地压缩、附件回弹。脚下尘点在脚步事件处发出，音效跟随同一事件；不能等动作结束才补一个不相关的声音。原站 `dust` 会扩成约三个多帧 puff，本地旧版本未识别该语义事件，且旧特效缩小了约一半，这会削弱体感。现已恢复事件语义与正常世界单位尺寸。

开场示例：0.3–3.5s 画棋盘，1.4s 起写坐标，1.9s 起分批引入角色，2.2s 起画周边，3.4s 起写状态，3.6s 后允许主要交互。普通表单 / 卡片可以使用同样的段落关系，压缩总时长；不要让熟练用户每次导航都等待长开场。减少动态效果时直接显示完整内容。

## 可移植的接口

```text
业务事件 / DOM button / pointer
 ├─ PaperMotion → matrix / fromScreen()
 ├─ InkTransition → progress 0..1
 ├─ IllustratedControl → 插画 + 语义 DOM + 墨迹说明
 └─ Character → clips / springs / semantic events
                     └─ SketchFeedback + SketchAudio
```

纸面：将 `cssTransform` 用于 DOM 图层；Canvas 使用相同 `matrix`；输入通过 `fromScreen()` 回到纸面坐标。不要只移动画面而让 hit testing 留在原位置。

墨迹：`Atlas.draw(ctx, key, { progress })` 可以绘制任何带时间图的插画 / 文字。`InkTransition` 负责可中断的包络，`DrawingSequence` 负责多组件开场顺序。场景稳定后回到静态缓存，避免每帧重算纸张与已完成的排线。

按钮：传自己的 icon、hoverIcon、textKey、语义 label；onclick 接实际业务操作。`drawIcon` 支持把多个部件 / 角色组合成一个道具。`dispose()` 删除监听器；宿主负责停止 RAF 和释放音频。

反馈：原始事件包含 `x/y`，来自当前动作的真实地面坐标。使用这个坐标发粒子，而不是已经登记的新业务位置。音频需要首次用户手势解锁，静音应同时关闭纸笔声；`SketchAudio.dispose()` 释放音频上下文。

## 为自己的项目制作资产

当前保存的是烘焙图集和时间图，没有取得原作者 `art/.../bake-*.mjs` 绘图生成器。可按这个公开格式制作自己的资产：

- RGBA 页面保存最终笔迹 / 插画；图集条目定义 page、x/y/w/h、trim、pivot、像素密度 ppu。
- 同尺寸时间图的 R 通道存笔迹出现的顺序（0–255）；每条线沿路径递增，连续线之间保留书写顺序。
- `hasTime: true` 表示启用时间图。当前适配使用与原 shader 相同的 `clamp((progress × 1.03 − time/255) × 60, 0, 1)`。
- 文字额外提供透明度和颜色压力 ramp；普通彩色插画用 RGBA 即可。
- 给轮廓准备两个或三个轻微不同的版本，而不是每帧重新随机抖动。保留相同 pivot / anchors 防止形体跳动。

Canvas 2D 适配只保留每个笔迹在展示分辨率下的一份可更新缓存，完成后直接使用原图；对大型场景或成百上千个同时书写元素，可以沿用原站的 WebGL 时间图着色器。

## 这次适配的边界

纸面效果是可逆仿射近似，原站是透视相机。开场保留主要时序与真实笔顺，角色动作部分仍来自原动画器；没有复刻全部周边剧情。声音是新的本地合成实现。独立实验台说明各模块如何独立运行，当前文字目录仍是固定原始笔迹；使用任意新文案时需要烘焙新资源。
